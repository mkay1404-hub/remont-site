# FORMA — сайт-портфолио ремонтной компании

Статический адаптивный сайт на HTML, CSS и JavaScript. Не требует сборки или установки зависимостей.

## Страницы
- `index.html` — главная страница
- `portfolio.html` — портфолио с шестью заготовками под фото
- `services.html` — перечень услуг
- `designers.html` — предложение о сотрудничестве для дизайнеров
- `contacts.html` — телефон, почта и Telegram
- `styles.css` — оформление и адаптивная версия
- `script.js` — мобильное меню

## Перед публикацией
1. Замените FORMA на настоящее название компании, если оно другое.
2. В `contacts.html` замените `+7 (000) 000-00-00`, `hello@example.com` и `https://t.me/your_telegram` на реальные контакты.
3. Чтобы добавить фотографии, создайте папку `images` и поместите туда фото. В нужном HTML вместо блока с классом `image-placeholder` вставьте, например:
   ```html
   <img class="portfolio-real-image" src="images/photo1.jpg" alt="Гостиная после ремонта">
   ```
   Затем добавьте в `styles.css`:
   ```css
   .portfolio-real-image { display:block; width:100%; height:100%; min-height:290px; object-fit:cover; }
   ```
   На главной странице для крупного изображения используйте `images/photo1.jpg`, в портфолио — `photo1.jpg`–`photo6.jpg` по порядку.
4. Проверьте, что заявленный список услуг соответствует фактическим работам вашей бригады.

## Публикация на GitHub Pages
1. Создайте новый репозиторий на GitHub.
2. Загрузите все файлы и сохраните структуру папки.
3. Откройте **Settings → Pages**.
4. В разделе **Build and deployment** выберите **Deploy from a branch**, ветку `main` и папку `/ (root)`, затем нажмите **Save**.
5. После публикации GitHub покажет адрес сайта в разделе Pages.
